# Getting Started
__________________

Linking all of the possible ways to contribute to Melancholy:

* Do you have an **AMAZING** idea? Join the discord server and let us know!
* Have you encountered to a bug, however you have no idea how to fix it? You can report it to the discord server OR you can post it in (issues)[https://github.com/tempestkaguya/melancholy/issues] but before you do so, make sure to search if the issue has been reported or not.
* Do you have any doubts with anything in particular? Again, join the discord server and you can ask the other users, for instance, "How can I make X?"
* Have you fixed a bug, improved X or added a new feature? Push your code to your own copy of the project and then open a PR (Pull Request)

# Q&As
__________________

How long does it take for a PR to be accepted or rejected? No more than 2 days.
What are the criterias we must respect?
* If a reviewer asks "what's the point of this change?" we expect you to answer them.
* If a reviewer finds a bug and it's already deployed in the system, we expect you to notify us so we can revert it.
* If a reviewer asks you a change must be done, depending on the severity and shows proof, we expect you to make that change.

# AI
__________________

We respect whoever uses AI, however we do not respect vibe coders who just prompt the hell out of claude code or codex without coding a single line. Optimizing your code with AI or using AI to generate comments is completely acceptable.
